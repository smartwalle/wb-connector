# 问候技能

通过 `greet` 工具向指定的人问好。

## 认证前置条件

调用本技能前，用户必须已完成登录授权。

**授权位置**：WorkBuddy 左侧栏「专家·技能·连接器」→「连接器」标签 → 找到本连接器 →
点击「连接」→ 浏览器打开登录页 → 用账号密码登录（示例账号 `demo` / `demo123`）。

首次调用时若返回未授权错误，说明连接器的登录态已失效。此时应提示用户重新连接该连接器完成登录，**不要反复重试调用**。

> 注意：连接器未完成授权时，其工具不会出现在会话的工具清单中 ——
> 此时在对话里搜索工具会一无所获，这是「未授权」而非「工具不存在」。
> 需要用户操作时，可使用 `workbuddy_request_mcp_connection` 工具请求连接。

## 工具说明

### `greet`

向指定姓名的人问好。

**入参**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `name` | string | 是 | — | 要问候的对象姓名，最长 64 个字符，首尾空白会被自动裁剪 |
| `language` | string | 否 | `zh` | 问候语语言。`zh` 为中文，`en` 为英文。不区分大小写，也接受 `zh-CN`、`en-US` 等常见别名 |

**返回值**

| 字段 | 类型 | 说明 |
|---|---|---|
| `message` | string | 最终展示给用户的问候语文本 |
| `language` | string | 实际使用的语言，`zh` 或 `en` |
| `name` | string | 归一化（去除首尾空白）后的姓名 |

## 调用示例

```
用 greet 工具向小明问个好
```

返回：

```json
{
  "message": "你好，小明！欢迎使用 WorkBuddy。",
  "language": "zh",
  "name": "小明"
}
```

## 错误场景

| 错误信息 | 含义 | 处理 |
|---|---|---|
| `参数错误: name is required` | 姓名缺失或全是空白 | 向用户确认要问候的对象 |
| `参数错误: language must be zh or en` | 语言取值不受支持 | 使用 `zh` 或 `en` |
| 未授权错误 | 登录态失效 | 提示用户重新连接连接器完成登录 |

## 注意事项

- 本技能只生成问候文本，**不发送任何消息**。若用户表达的是「发给他」「告诉他」等发送意图，本工具不适用。
